# OpenRepurpose 1.0.0

OpenRepurpose 1.0.0 is the first stable, local-first release for Windows and Linux.

## Verify before installing

Download the archive for your platform and its adjacent `.sha256` file. Compare its SHA-256 value
before extracting. The release-level `SHA256SUMS.txt` covers every portable archive. If `.asc`
files are attached, verify them with the maintainer's published OpenPGP key; absent `.asc` files mean
the release was checksum-only and must not be described as signed.

## Important limitations

- Windows x64 and glibc Linux x64 portable archives are released. Linux arm64 and musl are not.
- FFmpeg, ffprobe, whisper.cpp, and transcription models are not bundled. Configure audited local
  copies, then run `openrepurpose doctor`.
- Platform connections require your own developer credentials and may require platform review.
- Backups intentionally exclude secrets; reconnect accounts after restoring one.

See the included documentation and the project changelog for upgrade, self-hosting, security, and
platform-specific guidance.
