## Decisions
- Cache identity includes source-audio fingerprint, provider, model ID/version, language, and
  canonicalized output-affecting options. Cache reuse returns the original transcript rather than
  creating a duplicate.
- A transcript references exactly one media asset or transform derivative. Generated cues cannot
  replace a transcript once a user edit has been persisted.
- The provider contract accepts a managed local audio path and does not imply cloud upload;
  whisper.cpp remains a Packet 2 implementation behind this boundary.
- Managed whisper.cpp installs adopt a prepared official/build distribution directory atomically;
  acquisition and archive verification stay outside the bridge, so no Python, shell command, or
  silent download is required. Models use `<root>/<model-id>/<version>/ggml-model.bin` and remain
  user-initiated Packet 3 downloads.
- The provider requests whisper.cpp JSON sidecars and exposes segment cues only. It reports
  `wordTimestamps: false` rather than treating model tokens as linguistic words.
- Model catalog versions are pinned by the official whisper.cpp SHA-1 digest. Downloads come only
  from the published Hugging Face repository after an explicit user action and become installed
  only after checksum verification and an atomic rename.
- Model storage defaults under the local application data directory, can be overridden with
  `WHISPER_MODEL_DIR`, and preserves a 256 MiB safety reserve during preflight. Browser closure does
  not cancel a server-side transfer.
- The model manager extends the existing Routing Workbench / Workshop Ledger vocabulary without a
  design-system version bump; Base Multilingual is the recommended starting model.
