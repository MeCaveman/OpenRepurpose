# v0.1 progress

## Completed

- Packet 1: created the pnpm workspace and app/package skeletons for the CLI, server, web, core,
  database, media, platform SDK, shared contracts, and testkit boundaries; added strict tooling, CI,
  the Playwright shell, and ADR 0001.
- Packet 2: added host-native application directories, typed runtime configuration, Node
  SQLite/Drizzle persistence, transactional checksummed migrations, a settings repository,
  temporary-database helper, and the initial `openrepurpose doctor` diagnostic command.

## Decisions

- The initial deployment remains a local-first modular monolith. Durable behavior relies on explicit
  contracts and persistence, not shared process memory.
- Application paths use Windows AppData/LocalAppData or Linux XDG defaults. Absolute configuration
  overrides keep local PC, Docker, and VPS deployments on the same codebase.
- `@openrepurpose/db` uses Node 24's built-in SQLite driver through Drizzle's Node SQLite adapter.
  Migrations use `BEGIN IMMEDIATE` and a checksum ledger, and an altered applied migration fails
  fast. ADR 0002 records the choice.
- Media, jobs, account, workflow, and secret schemas remain deferred to their owning packets.
