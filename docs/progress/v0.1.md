# v0.1 progress

## Completed

- Packet 1: created the pnpm workspace and app/package skeletons for the CLI, server, web,
  core, database, media, platform SDK, shared contracts, and testkit boundaries.
- Added strict shared TypeScript configuration and package-local build/typecheck scripts.
- Added ESLint, Prettier, Vitest, and a Playwright shell with focused workspace/tooling tests.
- Added root development, build, typecheck, lint, format, unit-test, and E2E commands.
- Added Windows/Linux GitHub Actions verification and a committed dependency lockfile.
- Added ADR 0001 for the local-first modular monolith and later process/container separation.

## Decisions

- The initial deployment remains a single-process modular monolith, with delivery adapters,
  application/domain boundaries, and infrastructure adapters kept separate.
- Durable correctness must use persistence and explicit contracts; the initial composition may not
  make restart safety depend on shared in-memory state.
- Node.js 24.21.0 (Active LTS) and pnpm 12.4.2 are pinned. TypeScript 6.0.3 is the newest stable
  release compatible with the current maintained typescript-eslint peer range.
- `apps/server` is the initial composition root; no server, CLI, database, or integration behavior
  was pulled forward from later packets.

## Migrations/configuration

- No database migrations were added in Packet 1.
- Added pnpm workspace, TypeScript, ESLint, Prettier, Vitest, Playwright, Vite, and CI
  configuration.
- No runtime application environment variables or deployment-specific settings were introduced.
