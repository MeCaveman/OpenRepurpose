# v0.6 progress

## Completed

- Packet 1 added versioned Zod schemas and TypeScript domain types for trim, fit, audio,
  watermark, MP4 output, layered transform plans, and derivative provenance.
- Added deterministic normalization, canonical serialization, recipe hashing, and cache identity
  over source fingerprint, normalized plan, output-profile version, FFmpeg version, and encoder.
- Added migration `0018_transform_derivatives` and matching Drizzle schema with provenance,
  lifecycle/output constraints, a unique cache key, and recovery-oriented indexes.
- Recorded the transform model, cache semantics, and user-vs-destination distinction in ADR 0008.
- Added domain and migration tests for defaults, validation, stable hashes, cache invalidation, and
  incomplete-output constraints.

## Decisions

- Persist typed/versioned transform intent, never FFmpeg command strings or filter fragments.
- Preserve ordered user transforms separately from optional destination compliance transforms.
- Use normalized plans for persistence and hashing; step array order remains significant.
- Treat only a validated `succeeded` derivative as cache-reusable; Packet 3 will implement the
  reservation and file-validation lifecycle.
- Defer styled text overlays until v0.7 establishes predictable cross-platform font handling.

## Known issues

- This packet defines transform intent and durable records only. FFmpeg argument compilation,
  process execution, cache reservation/reuse, and derivative lifecycle transitions are intentionally
  not implemented yet.
- Text overlays and hardware acceleration remain deferred per the roadmap/ADR.
