# Changelog

All notable changes to OpenRepurpose are documented here. Releases follow semantic versioning;
the plugin SDK documents its independently stable compatibility range in `docs/PLUGIN_SDK.md`.

## 1.0.0 — 2026-09-24

First stable OpenRepurpose release.

- Local-first Windows x64 and Linux x64 portable distributions with pinned Node runtimes.
- Persistent SQLite jobs, restart recovery, backup/restore, and v0.9-to-v1 compatibility migration.
- BYO-credential YouTube, TikTok, Instagram Reels, Facebook Reels, Twitch, and Kick integrations.
- Local dashboard, CLI, authenticated API v1, and stdio MCP support.
- Release verification includes checksums, artifact smokes, migration/rollback, media/subtitle, Docker,
  platform-contract, and accessibility coverage.

See `docs/release-process.md` for artifact verification, upgrade, and publication procedure.
