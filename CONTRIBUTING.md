# Contribution policy

OpenRepurpose is available for you to use, study, modify, and fork under the
[GNU AGPL version 3 only](LICENSE). Forks and independently maintained derivatives are welcome, subject
to that license.

This upstream repository does **not** accept contributions. Please do not open pull requests, submit
patches, or expect feature requests and code changes to be reviewed or merged. If you need a different
direction, fork the repository and maintain your changes there.

Security vulnerabilities are not code contributions. Report them privately using the process in
[SECURITY.md](SECURITY.md).
